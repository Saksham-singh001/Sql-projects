# SQL Database Management Projects

This repository contains two SQL database management projects developed as part of my Data Analytics learning and practice.

## Projects

### 1. Hospital Management System

A SQL-based database project designed to manage hospital-related information and demonstrate database management concepts.

**Key Concepts:**
- Database and table creation
- Table relationships
- Primary and foreign keys
- Constraints
- SQL queries
- Stored procedures

### 2. Library Management System

A SQL-based database project designed for an online library management system.

**Key Concepts:**
- Database and table creation
- Table relationships
- Primary and foreign keys
- Constraints
- SQL queries
- Stored procedures
